# 🌸 Project: Her Smile 💖
> **Mission**: Bring Back My Sister's Smile 😊❤️

An interactive, responsive digital gift crafted with pure HTML5, CSS3, and Vanilla JavaScript. Built to turn sad, angry, or *naraz* moments into comfort, laughter, and genuine smiles.

---

## ✨ Features

- **Single-Page Digital Journey**: 9 progressive interactive screens guiding her emotions.
- **Glassmorphism & Micro-animations**: Modern pastel gradients, glowing buttons, and smooth CSS keyframe animations.
- **Interactive Challenges**: Interactive mood selectors, 3D card flips, humor-based dialog choices, and decryptable envelopes.
- **Ambient Floating Particles**: Lightweight, performance-friendly background elements (hearts, flowers, sparkles).
- **Background Music Player**: Configurable, browser autoplay-compliant toggle audio player.
- **Accessible & Fully Responsive**: Tailored for mobile, tablet, and desktop layouts with reduced-motion support.
